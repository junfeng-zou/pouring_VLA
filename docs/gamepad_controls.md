# 手柄遥操作控制说明

## 控制模式：笛卡尔末端控制

手柄摇杆直接控制机械臂末端执行器（EE）的空间运动，通过逆运动学（IK）自动解算各关节角度。

## 摇杆映射

| 手柄输入 | 功能 | 说明 |
|----------|------|------|
| **左摇杆 ↑↓** | EE 前后移动 (X) | 推杆向前 → 末端向前（+X） |
| **左摇杆 ←→** | EE 左右移动 (Y) | 推杆向右 → 末端向右（+Y） |
| **右摇杆 ↑↓** | EE 上下移动 (Z) | 推杆向上 → 末端向上（+Z） |
| **右摇杆 ←→** | EE 偏航旋转 (Yaw) | 推杆向右 → 末端绕 Z 轴顺时针旋转 |
| **LT（左扳机）** | EE 俯仰旋转 (Pitch–) | 按下 → 末端向下俯 |
| **RT（右扳机）** | EE 俯仰旋转 (Pitch+) | 按下 → 末端向上仰 |
| **LB（左肩键）** | EE 翻滚旋转 (Roll–) | 按住 → 末端逆时针翻滚 |
| **RB（右肩键）** | EE 翻滚旋转 (Roll+) | 按住 → 末端顺时针翻滚 |

## 按键功能

| 按键 | 功能 | 说明 |
|------|------|------|
| **A** | 开始/停止录制 | 切换当前 episode 的数据录制 |
| **B** | 丢弃当前 episode | 删除当前未完成的录制数据 |
| **X** | 夹爪开合切换 | 按一次切换：打开 ↔ 关闭 |
| **Y** | 重置环境 | 机械臂回到初始姿态，场景重置 |
| **Start** | 退出程序 | 安全退出遥操作 |

## 参数调节

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| `pos_action_scale` | `envs/pouring_env.py` | 0.01 m/step | EE 平移速度 |
| `rot_action_scale` | `envs/pouring_env.py` | 0.02 rad/step | EE 旋转速度 |
| `--deadzone` | 命令行参数 | 0.15 | 摇杆死区 |
